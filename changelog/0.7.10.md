# launchme 0.7.10

Released 2026-11-09.

## New
- **Desktop window colours** (Settings → Interface → Desktop window):
  - *Window theme*: nine dark themes for the background, panels and menus: Graphite (default), Navy, Forest, Sand,
    Plum, Sea, Wine, Indigo and Black.
  - *Accent colour*: switches, selections, progress and links. Choose from white (default), orange, mint, blue,
    turquoise, purple, pink, red, gold, Xbox Green, or any colour.
  - *Play button colour*: Play, Install and the other main buttons. It follows the accent by default.
  - TV mode keeps its own accent and button colours.
  - The widgets drawer, Friends and Profile in the desktop window use the theme too.
- **Coloured outline and glow** (Settings → Interface → Desktop window, on by default):
  - The selected poster is outlined in the cover's own colour, as in TV mode, or in the *Cover accent colour*.
  - A soft blurred glow of its art shows behind it.
- **Game details in the desktop window** have the game's art, blurred and faint, behind the page.
- **"…" in game details** (desktop window), after Hide, opens the game's menu.
- **Logs** (Settings → System → *Logs*, *Open logs folder*, Windows and Linux):
  - launchme records its starts and errors for the last 3 days in `logs/launchme-app`.
  - The *Save logs* switch in a game's *Launch options…* writes `logs/games/<game>`.
  - Games run by Aurelia are started with `play -vv`, and their output goes into that log.
- **HDR while playing** (Windows, in a game's *Launch options…*, off by default): switches the display to HDR when
  the game starts and back to SDR when it ends.
- **Launch options… for every game:**
  - Games of other stores get the *Save logs* and *HDR while playing* switches.
  - On Linux they also get their Windows build's Proton / Wine fields and the *Proton / Wine…* page, where the
    Proton version is set per game.

## Fixes
- *Change artwork* in the desktop window showed "no results" until Search was pressed a second time; the game's
  matches now show at once.
- Nintendo Switch 2 games had no platform mark on their posters.

## Changes
- Sorted by *Recently played*, the library no longer repeats the three *Continue playing* tiles above it.
- A thin divider separates the library's sections (All games, Favorites, Hidden) from Friends and Profile in the
  sidebar.
- The search field's key hint says Ctrl+F, which types in it (Ctrl+K still opens the quick search).
- *Details* is not listed in the "…" menu of a game whose details are already open.
