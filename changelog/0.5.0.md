# launchme 0.5.0

Released 2026-10-31. Includes everything from [0.4.9](0.4.9.md), which was not published on its own.

## New
- **Emulated games from the ROM folder** (Settings → Library → *Emulated games*: *ROM folder (built-in
  parsers)* by default): launchme reads an EmuDeck / ES-DE ROM folder with its own parsers, the systems,
  file types and emulators of EmuDeck's Steam ROM Manager parsers built in, so neither Steam ROM Manager nor
  Steam shortcuts are needed. The folder is found by itself (ES-DE's ROM directory, EmuDeck's settings) or
  chosen with *ROM folder* → *Change*. Every system folder with games counts; playlists (.m3u) and cue
  sheets hide their single discs and tracks; Steam ROM Manager's exclusions and new titles and ES-DE's
  hidden games apply when they exist. Games start through EmuDeck's launchers (with its cloud saves) without
  a console window, or through the emulator itself (RetroArch with the system's core). With the ROM folder
  in use, Steam ROM Manager's shortcuts of emulated consoles and its collections are left out; without a
  ROM folder, or with *Steam shortcuts (Steam ROM Manager)*, everything works as before.
- **More consoles on the Emulation row**: NES, Game Boy, SNES, N64, Game Boy Color, Game Boy Advance, DS,
  3DS, PS Vita, Master System, Mega Drive, Saturn, Dreamcast, Xbox, Xbox 360, Arcade and DOS get their own
  tiles (Steam ROM Manager shortcuts are sorted onto them too).
- **Add game decides by itself**: the "+" tile, *My games* → *Add game* and a file or folder dropped on the
  desktop window take a program or shortcut as a PC game, and a disc image or ROM as an emulated game with
  its console guessed (its folder under `roms`, its file type, what the disc holds), changeable on the new
  *Platform* row with the arrows or Enter. A folder works too: a PS3 game (`PS3_GAME\USRDIR\EBOOT.BIN`),
  a Wii U game (`code\*.rpx`), a folder with one game's ROM or a PC game's folder (its program found like the
  DRM-free scan does). The file picker has *Choose this folder*. An emulated game added by hand can carry its
  own *Emulator command* (`%ROM%` for the file).
- **Flix corner icons by pad** (Interface → Layout options → *Menu icons in the top-right corner*): they
  replace the bottom bar; Up from the first row or Guide focuses them, Left / Right walk them (Glance and the
  companion too), Enter opens one, Down or Back returns; the focused icon's name stands to their left.
- **Video delay**: a 1 s choice (Media → Videos → *Video delay*).

## Changes
- **Large game menu** is on by default and also used by Details, the libraries and search; its highlight
  glides between the options and a long list scrolls smoothly.
- **PSfive details**: laid out like Details (frosted cards with the description, the facts and the
  achievements, no title line); the screenshots and similar games slide like tiles, outlined like them.
- **Wallpaper**: on the home screen it waits for the focused game's own background instead of showing for a
  moment while it loads, and no longer shows through when one game's background fades into another's. The
  wallpaper picker opens with an empty search showing each source's best or newest.
- The first row keeps its tile size with the extra tiles; a longer row scrolls sideways.

## Fixes
- PSfive: "Play" no longer stays highlighted while the details are open, and Enter acts on them.
- *Change artwork* and *Wallpaper*: the page arrows can be reached with a pad or the keyboard.
