# launchme 0.5.9

Released 2026-11-02.

## New
- **Aurelia as a Steam replacement** (Settings → Library → Steam; it was *Manage games through Aurelia by
  default*): Aurelia is the library, not only the way games start. The account is the one signed in to Aurelia
  (no Steam account on this PC is needed); owned and installed games and their play time come from Aurelia;
  Steam's collections, Favorites and hidden games are pulled through Aurelia (read only, never sent back);
  recently played comes from Launchme's own history; every game installs, updates and starts through it. The
  row says what it takes over and that the library switches after a restart. Family Sharing games on Windows
  still need the Steam client (Aurelia's own Steam runtime is Linux only).
- **Downloading in Aurelia**: a game Aurelia downloads says so, instead of *Downloading in Steam*.

## Fixes
- Without a Steam client, Aurelia's library was never used: Launchme always guessed Steam's default folder,
  so the library stayed empty. It is used now whenever no Steam client with a signed-in account is here, and
  every game then goes through Aurelia (never `steam://`).
- A Steam game's play time comes from Aurelia when Steam's own count is not there.
