# launchme 0.7.13

Released 2026-11-11.

## New
- **Launchers and Deals in Stores** (Settings → System → Features → *Launchers and deals in Stores*, on by default): two built-in tabs before the
  store plugins' tabs, no plugin needed. *Launchers* has a card for Steam, GOG Galaxy, Epic, EA app, Ubisoft
  Connect, Battle.net, Amazon Games, Heroic, Lutris, Prism Launcher, RetroArch and ES-DE: open it, install it
  (winget, or the vendor's installer only with a valid signature; on Linux a Flathub client or the Windows build
  in a chosen Wine/Proton prefix), uninstall it or open its download page. Nothing installs on a single click.
  *Deals* lists free and discounted games from Epic, Steam and GOG plus GamerPower giveaways.
- **Launchers row** on the home screen (hidden by default, like Companies or Emulation): a tile per installed
  launcher.
- **Animated SteamGridDB artwork** (Windows): *Change artwork* lists animated grids and heroes first, and their
  tiles move. The focused card (the hovered one on the desktop) plays the chosen animation after a short rest.
- **Wallpaper Engine (Video)** wallpapers: a third source under Interface → Wallpaper → Animated, with the video
  wallpapers from your Wallpaper Engine subscriptions and own projects. Files play where they are, never copied.
- **Esc on the home screen** in TV mode opens the power menu when there is nothing left to close.

## Fixes
- Tile shadows on bright backgrounds no longer show bands (#23).

## Changes
- API keys (SteamGridDB, Steam Web API, RAWG, TheGamesDB, ScreenScraper) are saved encrypted for your user
  account. A plain key file is still read and is encrypted the first time.
