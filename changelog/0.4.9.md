# launchme 0.4.9

Released 2026-10-31.

## New
- **Artwork sources** (Settings → Media & data → *Artwork sources*, all on by default): *Change artwork* lists
  them under *Source* for every game, not only emulated ones: SteamGridDB, the Steam store (library art and
  screenshots of the game's Steam app, also for games from other stores), GOG, Xbox / Microsoft Store, Nintendo
  eShop, GameTDB (Wii, GameCube, Wii U, Switch, DS and 3DS covers; the disc image's ID or the title), TitleDB (a
  Switch title ID in the file name), TheGamesDB, Wikimedia Commons, ScreenScraper and ES-DE, each where it can
  have the game's art. The search field looks the typed name up in the source in view. TheGamesDB needs a free
  key (Settings → Media & data → Service keys → *TheGamesDB key*), like SteamGridDB and ScreenScraper; the others
  need none.
- **Wallpaper** (Settings → Interface → *Wallpaper*): pictures from Wallhaven and Danbooru (safe / general
  content only) or animated backgrounds from MotionBGs and Steam's animated profile backgrounds, picked in a
  gallery like *Change artwork*; the focused animated one plays its moving preview behind the gallery before it
  is downloaded. *From disk…* takes your own picture or video. It shows on the snitch screen, under the glass of
  Settings, Downloads, Devices, Glance and the chat, behind *Change artwork* and behind home tiles without a
  picture of their own (XMB categories, All games, Glance), each switchable in Interface → *Background and glass*.
  Without a wallpaper the launcher's backdrop of lights orbiting along lines stays, now also behind XMB's
  categories instead of a black screen.
- **All, Glance, Tarot and Companion tiles** (Settings → Interface → TV mode, *As in the layout* by default):
  *At the start of the row* or *At the end of the row* makes them tiles of the first row in every layout
  (shelves, XMB, Flix, PSfive, snitch; Metro's start page), so the screen behind them shows more often.
- **"Add game" tile** (Settings → Interface → TV mode, off by default): a plus tile in the first row opens
  *Add game* straight from TV mode.
- **PSfive details under the row** (Interface → Layout options, on by default): Down from Play / … raises a sheet
  with the game's description and facts, its Steam screenshots (Enter shows one full screen) and similar games
  from your library (Enter opens their details). With it on, the menu (quick bar) opens by moving Up above the
  tabs, and Down closes it.
- **Large game menu** (Interface → Windows and hints, off by default): the home screen's game menu as a large
  scrolling dialog with the game's cover and an icon beside each option, in every layout.
- **Metro light theme** (Interface → Layout options, off by default): a white page with dark tabs and outlines;
  the tiles keep their colours. The layout picker's Metro thumbnail shows it too.
