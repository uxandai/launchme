# launchme 0.5.6

Released 2026-11-01.

## New
- **Identify from the game's menu**: in TV mode a game no RAWG or ScreenScraper match names yet has
  *Identify game…* in its menu (the small one and the large dialog).
- **Identify game shows the file**: the dialog (TV mode and the desktop window) shows the game's ROM, program
  or folder under its title, cut at the start when it is long.
- **A ROM folder per system** (Settings → Library → Emulation → a system → *ROM folder*): a folder holding
  only that system's games replaces its subfolder in the main ROM folder; *Restore default ROM folder* goes
  back to it. It also works without a main ROM folder.
- **PlayStation 5 and Switch 2 systems**: emulated games of both, started by a program you choose with its
  own launch arguments (no emulator is assumed for them).
- **Switch 2 logo**: Switch 2 games show their own white Nintendo Switch 2 logo instead of the Switch one.

## Fixes
- A Switch or Switch 2 game kept as an unpacked folder is one game named after its folder (it was a game per
  part, named like *EffectScript*). A Switch 2 dump starts the newest update's `exefs\main`
  (`updates\<version>`), else the base's.
- The name picked in *Identify game* shows everywhere (tiles, the game's menu, details), also for games of
  the ROM folder and with *ROM titles* off.
- A title changed in *Edit metadata* in TV mode shows at once on the screen that is open (details, a system's
  games, search), as in the desktop window; before, TV mode kept the old name there.
- The default home's play time under the logo also comes from the game index when Steam's preview has none.

## Changes
- **Edit metadata in TV mode** has TV mode's own look (the dimmed screen, pill fields and glass buttons of its
  dialogs) instead of the desktop window's dialog.
- **Layout tiles slide**: Settings → Interface → *TV mode layout* shows 4.5 tiles at a time (the desktop
  window's settings 5.5, the walkthrough's last step 4.5) and slides sideways to keep the chosen layout in
  view; the tile cut at an edge shows there are more.
