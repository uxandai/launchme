# launchme 0.7.2

Released 2026-11-03.

## New
- **Search in Settings.** F3 or Ctrl+F (Y on the pad) opens a field over every setting of every category and of the
  pages behind their tiles; type a word (or several) and the list shows the settings that have all of them, the
  titles first, with where each one lives. A result opens its page with the row focused.
- **PSfive: Settings → Interface → Layout options → Darker background.** A slider that darkens the focused game's
  picture behind the row (0%: as before). It is in the theme studio's Layout tab too, and saved with a look.
- **Default layout: Settings → Interface → Layout options → Steam look.** Posters (it switches *Portrait posters* on),
  and *Recently played* becomes one row of one height: the first tile is a wide capsule in Steam's proportions, the
  others posters, and the focused tile does not grow. It is in the theme studio's Layout tab too, and saved with a look.
- **Lexend** among the fonts (Google Fonts, SIL Open Font License), shipped with the program in five weights.

## Changes
- **PSfive:** the Widgets and Menu icons in the top bar are gone. *Similar games* has no name under the focused
  cover. With *Icons instead of names* on, every category that has an icon (platforms, emulation, publishers,
  developers, favourites) stands in the bar before *More…* (which is three dots), *Recently played* has a clock icon
  too, and the shown category's icon carries a small dot.
- **Change artwork:** the dot beside a type is filled when the game has an artwork of that type in use, also one
  found by itself (Steam's, SteamGridDB's, the store's), not only one you picked.
- **Customize look:** the *Looks* tab is hidden for now (saving and loading looks comes back later).
- **Flix:** the code of the removed corner icons is gone with them.

## Linux
- **No text on a system without fonts for fontconfig** (a bare container, a fresh Arch): the launcher now looks for a
  plain text font in the font folders, Steam's interface and Proton, and uses it; without any it says so on stderr.
