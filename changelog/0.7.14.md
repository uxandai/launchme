# launchme 0.7.14

Released 2026-11-12.

## New
- **Local achievements for DRM-free games**: unlocks a game keeps in files on this computer (in its folder or a
  shared save folder) show in Details, the achievements screen, the desktop pane and the profile, with names and
  icons from the game's own schema or Steam's. With a Steam Web API key, a game folder that has no achievement
  schema gets one written for it, with its icons.
- **Achievement card in game**: an achievement unlocked while a DRM-free game runs slides in at the bottom right
  of the game's screen for a few seconds, on frosted glass, with its icon and a short sound. Clicks go through it.
  `launchme.exe --jump=achievement-test[:name]` shows a test card.
- **Game menu** in TV mode (hold on a game): play or install, details, remove from Recent, more options,
  uninstall. The Details menu is grouped and gains *Identify again*.
- **Recent searches** under the empty search field; X / Delete removes one after a prompt.
- **XMB**: the platform's logo instead of its name (Theme studio toggle); PC platforms list 12 games and *See all*.
- **Metro**: optional title and platform logo in the bottom-left corner instead of on the focused tile
  (Theme studio toggle).

## Changes
- Shift+Tab (or the chosen shortcut), the controller pair and the Guide/PS button open the in-game overlay's
  bottom bar first instead of the widgets.
- Shelves show the focused game's name on the hints' line, with its platform mark.
- Identify waits at least 3 seconds before accepting a match, so a manual pick is still possible.
- Flix: the side rail's focus springs between icons.
- Game menus have no hairlines.

## Fixes
- Linux: icons in the desktop window sit centred in their boxes.
