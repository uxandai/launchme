# launchme 0.7.3

Released 2026-11-04.

## Fixes (Linux)
- **The window is no longer one flat dark colour on Wayland with Vulkan.** Impeller's C API creates every swapchain at
  1x1 and clamps that to the surface's extents; a Wayland surface has no size of its own, so the window showed one
  stretched pixel. Such a surface now reports its window's size, and its swapchain is made anew when the window resizes.
- **Builds with fontconfig 2.18 and newer libstdc++ headers** (`fontconfig/fcfreetype.h`, `<climits>`).
