# launchme 0.7.12

Released 2026-11-10.

## New
- **CRT filter** (TV mode, Windows; Settings → Interface → Customize look → Other → *CRT filter*, off by default):
  the whole screen as a CRT, based on Timothy Lottes' public domain CRT shader. Choose the type (Scanlines only,
  TV, Trinitron, Arcade, VGA monitor) and set the horizontal and vertical screen curve, scanlines, mask strength,
  screen glow and the phosphor's afterglow, all live. Clicks land on what the curved picture shows, and the
  background grid over videos turns itself off while the filter is on.
- **Pad cursor** (Settings → Interface → TV mode → *Pad cursor (L3 + R3)*, on by default): L3 and R3 pressed
  together turn the pad into a mouse in TV mode. The left stick moves the pointer, R2 clicks, L2 goes back, the
  right stick scrolls; a small pad mark sits at the pointer while it is on. It turns off by itself when a game
  comes to the front.
