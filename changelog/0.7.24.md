# launchme 0.7.24

Released 2026-11-24.

## New
- **Supported Aurelia versions**: Launchme now carries a list of the Aurelia releases it was checked with. This
  release supports **Aurelia 0.3.1** (0.3 reworked Aurelia's commands and its automatic cloud saves).
  - *Install Aurelia* and *Update Aurelia* fetch that release by its tag, not simply the latest one.
  - An older Aurelia is reported loudly: a notification at start, *Update Aurelia to v0.3.1* in Manage Aurelia and
    the Settings row. Games do not start through it until it is updated.
  - A newer Aurelia is kept and noted as not checked with this Launchme.
  - Later Launchme releases move the list on. See [Supported versions](../docs/AURELIA.md#supported-versions).
- **Close to tray** (Settings → System → *Closing the window hides it in the tray*, off by default): ✕, Alt+F4 and
  the taskbar hide launchme in the tray. The tray icon's right-click menu has recently played games, the modes,
  downloads and *Close launchme*. On Linux it needs a desktop with a tray (KDE; GNOME with the AppIndicator
  extension).
- **Power button in the Widgets drawer**: a power icon next to the organize button opens the power menu. Press Up
  from the tiles to reach it first, then Right to reach the organize button. It works in Guide too.
- **Discord in Widgets** (Settings → System → Features): the Discord tile can open another client, such as Vesktop
  or Legcord, instead of Discord, PTB or Canary. *Choose program* picks it and *Restore* goes back to Discord.
- **Sidebar** (Settings → Interface → Desktop window → *Sidebar*, all on by default): show or hide *Store*,
  *Platforms*, and *Publishers and developers* in the desktop window's sidebar.
- **Aurelia cloud saves around play**:
  - Saves go up after the game ends, also when it ended with an error.
  - If Launchme closed while the game ran, its saves go up at Launchme's next start.
  - Turning on *Manage through Aurelia* for a game syncs its saves right away.
  - If cloud sync is off for a game in Aurelia (`aurelia config game <id> --cloud-sync off`), Launchme skips its
    own syncs for that game too.
- **Aurelia's log** (Launch options… → Launching → *Save Aurelia's log*, off by default): each launch through
  Aurelia, and each cloud sync, writes Aurelia's own detailed output to a log of its own.
  - *Save logs* and *Save Aurelia's log* each get a **…** button while on, which opens their folder. Aurelia's logs
    are kept in an `aurelia` folder inside the game's logs.
- **Launch providers for plugins**: a plugin can offer another way to start a store's games. It shows up in Launch
  options… → Launching, see the [Plugin API](../docs/plugins/API.md#launch-provider) and
  `sdk/examples/launch-provider`.

## Fixes
- *Close the game first* no longer appears when you update Launchme or install a Steam game while nothing is
  running. A game Launchme started but never saw running no longer blocks updates, Steam installs or Steam account
  switches. When a game really blocks one, the message names it.
- Update checks are no longer put off for good by such a game. When the game that held a downloaded update ends,
  *Update ready* comes back.
- Aurelia's texts about playtime and achievements are now right for each platform:
  - On Windows they count only while the Steam client runs on the same account.
  - On Linux, Steam counts neither for games started through Aurelia.
