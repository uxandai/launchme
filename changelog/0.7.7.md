# launchme 0.7.7

Released 2026-11-06.

## New
- **In-game overlay shortcuts** (Settings → Interface → *In-game overlay*, Windows): *In-game overlay keyboard
  shortcut* picks Shift+Tab (the default), Ctrl+Tab, Shift+F1, Ctrl+Shift+O or Off; *In-game overlay controller
  shortcut* picks Guide / PS (the default), View + Menu or L3 + R3, pressed together, for a PC where Steam or Xbox Game
  Bar owns Guide. The same shortcut closes the overlay. The keyboard shortcut is taken only while a game is in front.
- **Shelf: the case opens.** Enter on the focused case takes it off the shelf, opens it and slides out what is inside:
  a disc from a keep case, a game card from a Switch, Switch 2, DS, 3DS or PS Vita case, a 3.5" diskette from an Amiga
  big box. Play / Install, Details, a short description and the platform's logo are next to it. Back closes the case.
  Each console's case has its own proportions, size and plastic. PS2, PS3, PS4, Xbox 360, GameCube, Wii, Wii U and
  Switch cases use their real fronts (Twicethedad's [Game Cases](https://github.com/Twicethedad/Game-Cases), MIT).
- **Nintendo eShop first for Nintendo games:** *Identify game* asks the eShop before the databases for a Switch,
  Switch 2, Wii U or 3DS game, and takes a sure match (the title ID or the very title) at once. The game index fills
  in such games' description, publisher, release date and genres from the eShop before RAWG.

## Changes
- **Settings:** the in-game overlay is one switch, *In-game overlay*, in *Interface* (it was *In-game Guide* in
  *Controllers*). The *Guide / PS button* and *Widgets right away in games* options are gone: Guide / PS always
  opens the menu, and over a game the controller opens the overlay on the widgets.
- **Start-up:** the tiles wait until the libraries are in (Steam, GOG, Epic, the PC stores, ROMs), at most 2 seconds
  after the first games or until the first key or button press, then come in once. *Recently played* no longer
  reshuffles in front of you while the stores arrive.
- **Coverflow** has a *Variant* row: Shelf, Steelbook or Burned CD. The floppy disk and Switch cartridge views are
  gone; a library saved with one of them opens as Shelf.
- **Steam artwork** comes from Steam's own library cache first (already on disk for owned games), then SteamGridDB,
  so newly added Steam games show their art at once.
- **RAWG:** a game RAWG did not know is looked up again after a week (it was 30 days).

## Fixes
- **Identify game:** a game identified from a store's description (the eShop for a Nintendo game) no longer counts as
  unidentified.
