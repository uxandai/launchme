# launchme 0.7.15

Released 2026-11-16.

## Fixes
- Linux: the AppImage no longer crashes on start on SteamOS (Steam Deck). Parallel downloads shared one libcurl
  connection pool, which libcurl does not support across threads; DNS and TLS sessions are still shared.
- Linux: the build works again (the achievement card's frosted glass is Windows-only; on Linux the card shows
  without it), so this release has an AppImage again. 0.7.14 shipped for Windows only.
