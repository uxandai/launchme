# launchme 0.7.26

Released 2026-11-25.

## New
- **Merge versions of the same game** (Settings → Library → What to show, on by default): a game you have on
  Steam, GOG, Epic or Xbox, and its emulated copies, shows as one tile. **Change version**, next to *Play* /
  *Install* (TV details, the desktop pane and the game menu), lists every copy with its store or system logo;
  the one you choose is shown and started from then on, with its own art and platform badge.
- **Xbox helper 0.2.0** (Settings → Library → Xbox → *Xbox helper*; Launchme asks to download the new version):
  - **Offline play on this PC**: *Test* asks Microsoft whether this PC is the account's offline PC, *Turn on* /
    *Turn off* changes it (press twice: Microsoft allows only a few changes a year; the page shows how many are
    left). Games installed through Launchme then keep their license for up to 30 days without internet, and
    the game's details show *Offline until* the date.
  - **Game Pass**: a *Game Pass* badge on Game Pass games, *Game Pass* and *Purchased* filters next to *Sort by*,
    and a *New in Game Pass* row on the home screen.
  - **Achievements, playtime and last played** from Xbox Live, also for games the Xbox app installed.
  - **Updates**: *Update available* on games installed through Launchme with a newer package; *Update* in the
    game menu downloads only the changed files.
  - **Bundles**: games bought in a bundle appear one by one; the bundle's add-ons are no longer listed as games.
    The game's details count its add-ons (*Add-ons: N*).
  - **Clearer install errors**: the Microsoft Store device limit (with the page to remove a device), no license
    or an ended Game Pass, and packages only the Xbox app can install.
  - Linux: Visual C++ goes into the game's prefix (winetricks) before the first start of an Xbox game.
- **Library orders**: *Recently installed* and *Most played* in *Sort by* (TV and desktop).
- **Interface sounds** (Settings → Sound → *Interface sounds*): one sound set (*Minimal*, *Synthesized* or none),
  its own volume with a mute, and switches for moves, menus and Back, starting a game and notifications.
- **Music theme → Your own file…**: plays any .mp3, .wav or .flac from the disk.
- **Collections** in a game's quick menu (long press).

## Fixes
- PSfive: the background no longer turns darker in one jump just after Launchme starts in TV mode; the side
  shade and *Dim background* are there from the first frame.
- Xbox demos, betas and "Not Supported" entries of the account are no longer listed (installed ones stay).
- Choosing another sound set or turning notifications off no longer leaves the previous sound playing.
- A download's progress no longer fades the logo and summary in again in PSfive and the Stage view.
- Desktop *Recently played* thumbnails keep the cover's crop; an improved automatic crop is saved again.

## Changes
- Desktop dialogs dim the window more clearly; the Collections dialog uses a larger font.
