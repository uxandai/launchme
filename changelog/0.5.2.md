# launchme 0.5.2

Released 2026-11-01. Includes everything from [0.5.1](0.5.1.md), which was not published on its own:
emulators found and set by hand (Settings → Library → *Emulation*), the DRM-free page with the manually
added games, and *Add game* with *Choose file* / *Choose folder*.

## New
- **Controllers by state** (TV mode's *Controllers* and Settings → *Controllers*): each pad's tile has no
  grey fill; a green dot in its corner and a green border when it is connected, red when it is not, with a
  light travelling round the border (brighter on the focused tile). A disconnected pad is no longer dimmed.
- **Search with the game behind it** (TV mode's *Search*): the focused result's background, and after a
  moment its video, stay behind the results at half strength.

## Changes
- **Settings: Back is a dot at the top**, beside the *Settings* heading, as on the other screens: Up from
  the first category reaches it (pad and keyboard), Down returns; the wide button at the bottom is gone.
- **DRM-free folders → *Folders***: the scanned folders are a tile of their own; inside it *Add folder* and
  every folder with *Remove* (a second press confirms).
- **Settings → Library**: *Emulation* has its own icon and the platforms' cog instead of an arrow; the
  stores start a section of their own (*Stores*) below the DRM-free folders and *Emulation*.
- **Tarot** looks like the rest of TV mode: Launchme's typeface, muted grey cards and background, no night
  sky, sigil or gold ornaments.
- The bottom bar's sound icon draws its waves as arcs.
- Plugins in Settings no longer show their tag badges; a long description grows the row instead.
- Adding a game from the DRM-free page opens the list of manually added games with the new game focused.

## Fixes
- The test suite follows the large game menu (on by default since 0.5.0), the wallpaper rows and the
  thirty-one emulated platforms.
