# launchme 0.5.8

Released 2026-11-02.

## New
- **Excluded games, for every store** ([#18](https://github.com/uxandai/launchme/issues/18)): *Exclude* in a game's
  menu (also Steam games, DRM-free folders found twice and emulated games) asks first, then the game leaves the
  library, collections and search. Settings → Library → Visibility → *Excluded games (N)* lists them with their
  store; *Restore* brings one back, *Restore all* every one.
- **Flix side bar** (Settings → Interface → layout options → *Side bar*): icons at the left edge, as in streaming
  apps: home, one for each default category the page has (PC platforms, Emulation, Publishers, Developers,
  Favorites; it scrolls to its row), search and all games; at the bottom the profile, the menu and the widgets.
  Left from a row's first tile enters it, Up/Down walk it, Right or B goes back.
- **Icons instead of names** on PSfive's and Metro's own tabs: PC platforms, Emulation, Publishers, Developers and
  Favorites as icons; other collections keep their names.
- **An emulator per game**: an emulated game's details' "…" → *Emulator* walks *Automatic* (the system's), the
  system's other emulators found on this PC and *Another program…* (any program, picked once), as does the desktop
  window's game menu. Made for Switch 2 dumps that need another build than the rest.
- **Publishers and developers, tidier** ([#18](https://github.com/uxandai/launchme/issues/18)): each row has its own
  switch, *Fewest games* (1, 2, 3 or 5; 3 by default) leaves out studios with fewer games, and the studios with the
  most games come first. A logo's menu in TV mode moves it earlier or later or hides it; Settings → Library →
  *Hidden publishers and developers* lists the hidden ones, each with a switch to show it again.
- **Switches for Recently updated and Not played yet**, the Steam rows of an account with no collections.

## Fixes
- **Favorites can be switched off**: hiding the Favorites collection (Settings → Library → *Collections*) now hides
  it everywhere: no Favorites shelf or desktop section, no stars on the details screen or the desktop pane, nothing
  to add to it; what it holds stays for when it is shown again.
- A DRM-free folder that is one game's own folder (its program at the top, beside its uninstaller or Steam's files)
  is that game, not one game per subfolder (a mod tool beside it was found as a game of its own).
- In TV mode the game menu's *Identify game* row was chosen but not drawn; every row of the menu shows now.
- A Switch 2 dump added by hand starts from its `exefs\main`, not from the folder picked.
- A question's explanation (uninstall, remove, exclude) shows under it in TV mode too.

## Changes
- *Identify game* sits under *Edit metadata* in the desktop window's game menu too.
