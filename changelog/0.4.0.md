# launchme 0.4.0

Released 2026-10-29.

## New

- **Linux (highly experimental, work in progress)**: the whole launcher now also builds and runs natively on
  Linux: the same TV mode and desktop window, drawn on the GPU (Vulkan, else OpenGL), with SDL3 for the
  window, pads and sound. It reads Steam (native, Flatpak, Snap), Heroic (Epic and GOG), Lutris, Prism Launcher and
  your own games. Expect rough edges and missing pieces: no FPS reading, the in-game Guide opens in the launcher's
  own window, and web pages need WebKitGTK (else they open in your browser). Building and status:
  [docs/linux-port.md](../docs/linux-port.md).
- **Linux: Proton and Wine** (Settings → *Compatibility*): Windows games (a store's, your own `.exe`, a DRM-free
  folder's) run through umu-launcher, Proton or Wine.
  - Downloads of GE-Proton, UMU-Proton, Proton-CachyOS, Kron4ek's Wine builds, DXVK, VKD3D-Proton, DXVK-NVAPI and
    umu-launcher itself; Proton, Wine and the tools Steam, Heroic and Lutris already have are found too.
  - A prefix manager: each game's own prefix or a shared, named one, its tool and size, winecfg, regedit,
    winetricks / protontricks, running a program in it, ending its processes, deleting it.
  - Per-game and default options as folding sections: synchronisation (ntsync/fsync/esync), gamescope, MangoHud,
    GameMode, FSR, HDR, Wayland, DLSS / FSR 4 / XeSS upgrades, NVAPI, EasyAntiCheat and BattlEye runtimes, DLL
    overrides with presets, environment variables (with ProtonDB favourites), locale, scripts before and after,
    a wrapper, logs.
  - protonfixes for store games: their umu-database ID goes to umu-run (and to GE-Proton without it).
  - **Add a game from its installer** (Compatibility → *Games*, also in *Manually added games*): the installer runs
    in a new prefix named after the game; afterwards Launchme offers the program it installed and adds the game,
    in that prefix.
  - A Windows game started with no Proton or Wine on the computer downloads GE-Proton first, then starts by itself.
  - The start notification names options whose program is missing ("Starting without: MangoHud is not
    installed"); a failed start says why. The game's page opens its **Last launch's log**.
- **Shortcuts** (the desktop window's game menu → *Shortcuts*; on Linux also the game's *Proton / Wine* page): a
  **Desktop shortcut** and a **Start menu** entry for the game (Linux: the **Applications menu** and the desktop),
  and on Linux **Steam** (with the game's artwork; Steam sees the game run, also in the Steam Deck's Game Mode).
  They start the game through Launchme, with its launch options. Launchme never overwrites someone else's
  shortcut of the same name.
- **Not installed in Recently played** (Settings → Library → Visibility, off by default): games not installed and
  games added without their file join *Recently played* (TV mode and the desktop window), by the date they were
  added to the library.

## Changes

- The computer and its display stay awake while a game started from Launchme runs (not while it is suspended).
