# launchme 0.7.27

Released 2026-11-25.

## New
- **Advanced filter…** (TV: *Filters* → *Advanced filter…*; desktop: the filter menu): rules put together by
  clicking instead of typing a query: title, studio or genre contains or does not contain a word, game mode,
  store, status, rating, length and year. For example *Tekken* without *Tag Tournament*, or every game of one
  publisher that has co-op.
- **Smart collections** (*New collection* → *Smart collection*): a collection built from the same rules that
  fills itself as the library changes; *Rules* edits them, and games can still be added or removed by hand.
- **Switch game** in the Guide over a game: the running and suspended games rise from the button with their
  covers; picking one brings its window to the front (a suspended one resumes; with *Quick Resume* on, the game
  left behind is suspended).
- **Install queue**: a GOG, Epic, Amazon or Xbox game asked for while another downloads waits in *Downloads* and
  starts in turn instead of being refused; choosing a queued game in *Downloads* takes it off the queue.
- **Library orders** by rating and by HowLongToBeat length; on Linux the sensors also show GPU, VRAM, RAM and
  free space.

## Fixes
- *Switch game* left the picked game behind the overlay; it now comes to the front, and the overlay goes.
- *Switch game* with a controller: the pick happens when A is released, so the game brought forward no longer
  receives the A press.
- Switching or resuming with *Quick Resume* could freeze Launchme: the game left behind is now suspended only
  after the picked one has the foreground.
- A suspended game in *Switch game* showed its initial instead of its cover.
- Grid with *Collections as tiles*: the collection tiles scroll smoothly together with the games instead of
  jumping, and Down from a collection tile goes to the first row of games.
- Aurelia: saves left to upload after Launchme closed during a game are no longer uploaded for a game that is
  now started through the Steam client, or while the game still runs; a failed Aurelia start names the game.
- Code review fixes across the launcher (launch environment, worker results, desktop sort and filter
  persistence).

## Changes
- The gold border on games with every achievement unlocked is gone.
