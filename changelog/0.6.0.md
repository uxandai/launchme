# launchme 0.6.0

Not released yet.

## New
- **Aurelia downloads can be paused and resumed.** A transfer has *Pause download*, *Cancel download* and, once it
  waits in Aurelia's install backlog, *Resume download*, *Remove from queue* and *Remove from queue and delete
  downloaded files*. Paused and stopped downloads are shown as paused instead of running.
- **Aurelia library maintenance**: *Point to moved files* (relink), *Register existing files* (import a game that is
  already in a Steam library) and *Find duplicate installs* (report only).
- **Widgets pinned on the game's screen.** In Guide over a game, a click (or A) on the FPS, CPU or GPU tile pins it in a corner of the game; another click lets it go.
  Pinned widgets stay while the game is in front and Guide is closed; a dot marks them in the drawer.
- **Guide in a game opens on the widgets** (*Controllers → Widgets right away in games*, on by default); Back leaves them for the quick bar.
- **FPS widget without administrator rights.** If the trace is denied, *Settings → Widget FPS gry* offers *Grant* (one UAC prompt adds you to *Performance Log Users*; sign out and in once). Launchme itself still runs unelevated.

## Fixes
- With *Guide in games* on, the launcher no longer hides in the notification area or yields priority behind a game, so Library, Settings and the rest opened from Guide appear in a live launcher instead of a frozen one.
- Entries of Aurelia's install backlog (paused, stopped, interrupted) were listed as active downloads.
