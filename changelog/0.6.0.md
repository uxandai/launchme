# launchme 0.6.0

Not released yet.

## New
- **Aurelia downloads can be paused and resumed.** A transfer has *Pause download*, *Cancel download* and, once it
  waits in Aurelia's install backlog, *Resume download*, *Remove from queue* and *Remove from queue and delete
  downloaded files*. Paused and stopped downloads are shown as paused instead of running.
- **Aurelia library maintenance**: *Point to moved files* (relink), *Register existing files* (import a game that is
  already in a Steam library) and *Find duplicate installs* (report only).
- **Companies** (*Settings → Library → Publishers and developers → Firmy*): publishers and developers as one list, in Tryb TV and the desktop window, with no repeated logos or categories. It replaces the two separate lists (they switch off); turning it off brings them back.
- **FPS and limiter** (*Settings → System → FPS i limiter*, Windows): the FPS widget, a frame-time graph (last six seconds, in the tile and in the pinned widget) and a frame limiter, global or per game.
  The limiter is opt-in: it loads `launchme_limiter.dll` into the running game (64-bit, Direct3D 10/11/12) and holds `Present` to an exact interval; *Precise smoothing* spends the last milliseconds of each frame spinning for the most even pacing.
  Games with an anti-cheat in their folder are left alone, 32-bit, Vulkan, OpenGL and Direct3D 9 games are reported as unsupported. Using it in online games is at your own risk. Linux has MangoHud.
- **FPS and limiter, more choices.** *Widget over the game*: a switch for each line (FPS, CPU and GPU temperature, RAM and VRAM usage). *Limiter mode*: *Even frames* (each frame waits for its slot in Present, the most even, adds latency) or *Low latency* (adaptive: the game starts its next frame as late as it can still make the slot; in the test 1.3 ms instead of 12.6 ms of added wait at 60 FPS). *Limiter badges*: LIMIT 60 and SMOOTH / LOW LATENCY chips on the widget while the limiter works. The frame-time graph keeps a fixed scale, so a spike no longer changes its height.
- **Widgets pinned on the game's screen.** In Guide over a game, a click (or A) on the FPS, CPU or GPU tile opens a dialog like Zasilanie: show or hide that widget (the first row), the layout (a list or a one-line strip with spacing), coloured labels, the size (100% is the largest, down to 50%) and the frame graph. The same options sit in *Settings → System → FPS i limiter*, each with an explanation.
- **CPU temperature from MSI Afterburner.** Windows gives no CPU temperature without a driver. When Afterburner runs, launchme reads that one number from its shared memory (nothing is injected, no driver is used); everything else it measures itself. *CPU temperature source* switches this off.
  Pinned widgets stay while the game is in front and Guide is closed; a dot marks them in the drawer.
- **Guide in a game opens on the widgets** (*Controllers → Widgets right away in games*, on by default); Back leaves them for the quick bar.
- **FPS widget without administrator rights.** If the trace is denied, *Settings → Widget FPS gry* offers *Grant* (one UAC prompt adds you to *Performance Log Users*; sign out and in once). Launchme itself still runs unelevated.

## Fixes
- **Shift+Tab** over a game shows the bottom bar again (only the pad's Guide opens on the widgets); opening *All games* and the other pages from Guide now brings the launcher to the front instead of leaving it behind the game.
- Turning on *Widget FPS gry* pins the FPS widget on the game's screen at once.
- With *Guide in games* on, the launcher no longer hides in the notification area or yields priority behind a game, so Library, Settings and the rest opened from Guide appear in a live launcher instead of a frozen one.
- Entries of Aurelia's install backlog (paused, stopped, interrupted) were listed as active downloads.
