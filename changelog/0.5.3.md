# launchme 0.5.3

Released 2026-11-01.

## New
- **PS4, PS Vita and ScummVM** (Settings → Library → *Emulation*): shadPS4, Vita3K and ScummVM join the
  emulators found on their own (EmuDeck's launchers and Emulators folder, ES-DE, the usual install folders).
  PS4 games are shadPS4's shortcuts in `roms\ps4\shortcuts` and games kept as folders (`eboot.bin`); PS Vita
  games are installed games started by their title ID; ScummVM games are `.scummvm` files (RetroArch's
  ScummVM core when the standalone program is missing).
- **Missing RetroArch core**: a system whose games start through RetroArch without its core says *Core
  missing* in the list, and its page names the file and where RetroArch downloads it (Main Menu → Online
  Updater → Core Downloader).

## Changes
- **Power menu in TV mode** looks like the large game menu: a wide panel with its icon, tall rows with an
  icon each, the white button gliding between them; the PC's own actions stay red.
- **Controllers** (TV mode's *Controllers* and Settings → *Controllers*): each tile is a quiet grey card like
  the sound devices', with the state's dot in its corner; only the focused tile is framed, and the frame
  glides between the tiles as on the companion cards.
- **TV mode layout** (Settings → Interface): the layout cards and their gliding frame follow the companion
  cards.
- These frames (and the companion cards') follow Settings → Interface → *Glow animation*: pulsing when the
  glow pulses, the travelling light when it travels.
- The companion's level badge is a frosted glass pill, as the other buttons.
- A page opened from another page shows that page as its way back (*‹ Emulation* on a system's page).
- Spanish and Brazilian Portuguese cover every text again (728 were missing, also from before 0.5.0).

## Fixes
- **Holding a direction on the pad** repeats as fast as a held arrow key (Windows' keyboard repeat rate);
  it was several times slower.
- Tarot follows a font chosen in Settings → Interface → *Font* at once, not after a restart.
- The emulator command row of a system's page no longer shows an *Open* button that did nothing.
