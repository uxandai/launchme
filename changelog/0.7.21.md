# launchme 0.7.21

Released 2026-11-18.

## New
- **Launch scripts** (a game's menu → *Launch options…* → *Scripts* tab, TV mode and the desktop window; also *Edit game*
  and *Add game*): three commands per game, run *Before the game starts* (Launchme waits up to two minutes for it),
  *After the game has started* and *After the game has exited*. Each field has a *Test* button that runs it at once
  and shows its exit code and last line of output. An empty field runs nothing.
  - Windows: Windows PowerShell runs the command, so paths to `.bat`, `.cmd`, `.exe`, `.ps1` or `.vbs` files with
    their arguments work (an unquoted path with spaces too), as do `Start-Process` and several commands joined
    with `;`. Linux: `/bin/sh -c`.
  - Scripts run hidden in the home folder with `LAUNCHME_GAME_NAME`, `LAUNCHME_GAME_KEY` and `LAUNCHME_SCRIPT_PHASE`
    set. A failed script shows a notification; with *Save logs* its outcome goes to the game's log. When a game does
    not start after its script before the launch ran, the script after the exit runs to undo it.
  - In TV mode LB / RB switch between the *Launch* and *Scripts* tabs.
- **XMB *Dimmed icons*** (Settings → Interface → Layout options, off by default): top-row tiles other than the focused
  one are translucent, so the chosen one clearly stands out.
