# launchme 0.7.23

Released 2026-11-23.

## New
- **Game mods** (a game's menu → *Launch options…* → *Mods* tab, TV mode and the desktop window; Windows): one-click
  installs of ReShade, RenoDX, OptiScaler, DLSS, DLSS 5 and ANR frame generation into the game's program folder.
  - Each mod has an install method picked from a list (ReShade as `dxgi.dll` for DirectX 10–12, `d3d11.dll`,
    `d3d12.dll`, `d3d9.dll` or `opengl32.dll`; OptiScaler's file; which DLSS DLLs to replace; ANR full or as an
    OptiScaler add-on), *Update* for one already there and *Remove* for Launchme's own, which puts the game's
    original files back. ReShade comes with the standard shaders when the game has none.
  - The folder is found from the game's running program (Unreal's `Binaries\Win64` too) and can be changed with
    *Change…*. An emulated game's mods go into its emulator and apply to all of its games.
  - A game with anti-cheat asks before the install: mods are for offline play only.
  - Settings → Library → Launching → *Game mods*: the preferred method of each mod, *Mod badges* (on by default:
    the game's page shows a line with what is enabled in it, HDR and logs included) and *Downloaded mods* to clear
    the cache.
- **Launch options for every game**, games from ROM folders included, under one name (*Launch options…*). Its
  *Launching* tab gathers what starts the game, a row each: *Emulator* (an emulated game's own emulator, or
  *Another program…*), *Steam account*, *Manage through Aurelia* with **…** to its Aurelia page, *Save logs* and
  *HDR while playing*. A line under the title says what launches the game: Steam, Aurelia, an emulator, its own file
  or its store's client. Choices are kept when you press *Save*.

## Changes
- The launch options panel in TV mode looks like Settings: a card per row over the full width, the tabs in one
  track, lists for choices, and a focus outline that springs between the tabs, rows and buttons. LB / RB switch the
  tabs; A opens a list, Left / Right step through it without opening it.
- The desktop window's menu has no submenu left for a single entry.

## Fixes
- *Another program…* as a game's emulator in the desktop window now opens the program picker.
