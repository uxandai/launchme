# launchme 0.5.7

Released 2026-11-01.

## New
- **Look for games again** (Settings → Library → Emulation → a system): reads the ROM folders again (new games,
  an update, games removed), shows how many games the system has and says so when it is done.
- **Switch 2 dumps in any layout**: every folder of the system holding an `exefs\main` is a game, also with no
  file of a ROM extension (such as *Fire Emblem Fortunes Weave*'s `131072\exefs\main`). It starts from the newest
  `updates\<version>\exefs\main`, else `base\exefs\main`, else `exefs\main`, else `<number>\exefs\main`.
- **Add game** takes a Switch 2 dump too: its folder or its `exefs\main`, started and identified as the ROM folder's
  scan does it. A dump inside a `switch` folder is a Switch game; *Platform* still changes it.

## Fixes
- A title changed in *Edit metadata* stays: a system's games in TV mode (its tile on *Emulation*) showed the old
  name, and saving a new title dropped the game's identification (*Identify game* came back and HowLongToBeat
  went with it). The identification now stays; only what was looked up by the old title is fetched again.

## Changes
- **Games added by hand are DRM-free games** ([#17](https://github.com/uxandai/launchme/issues/17)): one *DRM-free*
  tile on *PC platforms*, one library and tab in TV mode, one section in the desktop window, holding the scanned
  games and those added by hand (their list stays under Settings → Library → *DRM-free folders* → *Manually added
  games*).
- **No "Choose file" on the tile** ([#17](https://github.com/uxandai/launchme/issues/17)): a game added without its
  file says so on its button and in the hints only.
- **PC is no console** ([#18](https://github.com/uxandai/launchme/issues/18)): Steam shortcuts to PC programs stay
  in the library and no longer make a *PC* tile on *Emulation*.
- *Identify game* moved down the game's menu, where *Edit metadata* is.
