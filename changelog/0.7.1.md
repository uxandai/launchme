# launchme 0.7.1

Released 2026-11-03.

## Fixes (Linux)
- **The AppImage no longer crashes at start on Arch** (and other distributions with a newer libstdc++), with
  Steam installed. `libimpeller.so` exported the `_Unwind_*` functions of its statically linked libunwind, which
  replaced the system's unwinder for the whole process: no `catch` could find its handler and the first thrown
  exception ended in `std::terminate`. The library now exports only its C API (`launchme_impeller.map`).
- **Companions and logos with transparency had red and blue swapped on OpenGL** (a blue-green companion). Impeller's
  OpenGL ES backend takes B8G8R8A8 bytes as RGBA; pictures are uploaded as RGBA there. Vulkan was right.
- **Reading `loginusers.vdf` throws no exception any more:** `"users"` and every other non-numeric key went through
  `std::stoull` and a `catch` on each start.

## Tests
- `impeller_d2d` draws a premultiplied BGRA picture with alpha (plain, cubic, half alpha) and checks the channels on
  both OpenGL and Vulkan.
