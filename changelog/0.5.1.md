# launchme 0.5.1

Released 2026-10-31.

## New
- **Emulation settings in one place** (Settings → Library → *Emulation*, a tile under *DRM-free folders*):
  the console row on the home screen, where emulated games come from (*ROM folder* or *Steam shortcuts*),
  the ROM folder, names and artwork matched by ROM, and a row for every system with games (the others
  folded under *Other systems*) saying which emulator starts it and how it was found.
- **Emulators found and shown** (Emulation → a system): each emulator is looked for in order: the program
  chosen by hand, EmuDeck's launcher script (its `.ps1` / `.sh`, with the program it runs shown beside it),
  EmuDeck's Emulators folder, ES-DE's find rules (`es_find_rules.xml`), the Windows registry (App Paths and
  installed programs), the folders installers use (Program Files, `%LOCALAPPDATA%\Programs`, Scoop, Steam),
  `PATH`, and on Linux flatpaks and AppImages in `~/Applications`. EmuDeck is no longer needed: a standalone
  ES-DE, an installed or portable emulator, or one on `PATH` is found too.
- **Emulators set by hand** (Emulation → a system): *Emulator* picks which one starts the system's games
  (*Automatic*: the first one found; PS1, PSP, DS, GameCube and Wii can also run on RetroArch), *Program* →
  *Browse…* points at the emulator's file (*Detect again* undoes it), *Launch arguments* replace its default
  ones (`%ROM%` places the game's file, `%CORE%` RetroArch's core), and *Command* shows what a game starts
  with. *Open folder* opens the emulator's folder.
- **Add game: Choose file / Choose folder** (the "+" tile, Settings → Library → DRM-free folders → *Add game*;
  Tryb TV and the desktop window): two buttons above the fields. *Choose folder* takes one game's folder (a
  PC game, a PS3 or Wii U game, a folder with one game's ROM), a ROM folder (it becomes the emulated games'
  ROM folder and is scanned at once) or a folder of many games (it joins the DRM-free folders and is
  scanned). A folder dropped on the desktop window is handled the same way.

## Changes
- **Settings → Library**: *DRM-free folders* come first, *Emulation* under them, then Steam and the stores.
  *Manually added games* moved into the DRM-free page (*Add game* and *Covers* at its top, then the scan and
  the folders, then *Manually added games* and *Found games*); it works whether the folders are scanned or
  not. *Publishers and developers* moved into *Collections*; the *Extra sections* group is gone. The
  emulation names and artwork switches moved from Media & data to *Emulation*.
- *Choose file* no longer offers *Choose this folder* for a new game (*Choose folder* does that).

## Fixes
- A game's background video no longer plays on under Settings (Tryb TV and the desktop window).
