# launchme 0.6.2

Released 2026-11-03.

## New
- **Change artwork → "Local" source.** Every picture added with *From disk…* is now kept as a variant of the game
  and offered as its own source (*Source: Local*, the list of sources appears as soon as the game has one). After
  adding a file the browser switches to *Local* and shows the new picture as the one in use; later any of your own
  pictures of that type can be picked again from the gallery.
- **Change artwork → From disk… is a board.** Instead of a list, the six types (square, background, logo, poster,
  wide tile, disc) are tiles with small illustrations drawn in the real proportions, with a caption. Pad, keyboard
  and mouse move over the 3 × 2 grid; *Choose file…* sits under it.
- **Set / not set marks.** The type list on the left of *Change artwork* and the *From disk* board show a filled dot
  for a type you already set an artwork for and an empty ring for one you did not (TV mode and desktop).

## Changes
- **Stores share one frame (TV mode and desktop).** The catalog and every store plugin (StoolerStore, EmuStore, …)
  use the same centred column: back button, tabs sized to the number of stores (1-3) with LB/RB hints at the sides,
  the search field and the status line below it. The field looks like the global search (big hint text, no blinking
  caret when empty); on a store page you can type anywhere, no need to focus the field first. The store plugin is
  named StoolerStore. Store pages on the desktop are native lists, like the catalog.
- **EmuStore** puts every download into `<ROM root>\switch` (they are ports, not per platform) and no longer shows the
  "configure" message twice.

## Fixes
- **Taskbar: pinned launchme opened as a second icon.** The window now carries launchme's own AppUserModelID, so a
  pinned shortcut and the running window are the same taskbar button (unpin and pin it once more if it was pinned
  before).
