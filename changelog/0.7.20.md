# launchme 0.7.20

Released 2026-11-17.

## New
- **PS3-style XMB customization** (Settings → Interface → Layout options and Customize look → Layout, all off by
  default):
  - *Landscape tiles*: 920:430 horizontal game capsules instead of square covers or portrait posters.
  - *“Recently played” as an icon*: collapses Recently played into a single clock-icon tile with its games listed in
    the column below instead of separate games across the top row.
  - *“Favorites” as a star icon*: draws a star icon on the Favorites collection tile instead of the 2×2 four-cover
    preview.
  - *Pulsing title glow*: subtle PS3-style pulsing Gaussian glow behind the focused game's title.
- **TV background upscaler** (Settings → Interface → Background & glass → *Upscale sub-4K backgrounds*, on by
  default): upscales lower-resolution game backgrounds and static wallpapers in TV mode using AMD FidelityFX FSR 1.0
  (EASU + RCAS) on Windows and a 5-tap Catmull-Rom + CAS shader on Linux.
- **4K game backgrounds** (Settings → Media & data → Covers → *4K game backgrounds*, off by default): downloads and
  keeps game backgrounds at up to 3840×2160 from Steam (`library_hero_2x.jpg`) and SteamGridDB instead of 1440p and
  local 1920×620 copies, with a 4K badge in *Change artwork*.
- **Boot videos and exit animation** (Settings → Interface → *Startup and exit*): play a startup animation with sound
  in TV mode from Steam Deck Repo or from disk (WebM/MP4, optional *Randomize on startup*, 16:10 *Fit* or 16:9
  *Fill screen*, full-screen preview; any button skips), and toggle or recolour the closing light-trail animation
  (*Exit animation*, on by default).
- **Nintendo Switch and Switch 2 background trailers**: background videos in TV mode now also fetch trailers from
  nintendo.com for emulated Switch and Switch 2 games.
- **Frame-time HUD** (Widgets → FPS options and in-game overlay): *Frame time (ms)* (off by default) shows mean frame
  time in milliseconds, and *Frame-time spikes (max ms)* (off by default) shows the slowest frame of the last second
  beside it.
