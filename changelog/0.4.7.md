# launchme 0.4.7

Released 2026-10-31.

## Fixes
- **Back from a game without the focus** (Windows): with *Hide to tray while playing* on (Settings → Library →
  Launching), the launcher came back on top when the game closed, but the keyboard and the pad still went to
  another program (the terminal or browser Windows activated when the game's window went away) until the
  window was clicked. A program that came forward as the game ended is now seen as left there by the game:
  the launcher takes the foreground, also while Windows' foreground lock still holds after the game's last
  keypress, and tries again for two seconds if Windows refuses. A program the user switched to during the
  game keeps the screen; the launcher waits right behind it instead of covering it without the focus.

## Changes
- Releases: the `SHA256SUMS` of a release's files are signed with Sigstore, in `SHA256SUMS.sigstore.json`
  (0.4.6's were attached by hand, unsigned). To check them:
  ```sh
  cosign verify-blob SHA256SUMS --bundle SHA256SUMS.sigstore.json \
    --certificate-identity https://github.com/uxandai/launchme/.github/workflows/release.yml@refs/tags/v0.4.7 \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com
  sha256sum --check --ignore-missing SHA256SUMS
  ```
